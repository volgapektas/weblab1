# Assignment 1 - Multi-Page Semantic HTML5 Website

## 1. Theme

The website represents **DevCore Solutions**, a fictional student-led software development agency specializing in web, mobile, and system design services.

## 2. File Organization

The repository is structured strictly using relative paths to ensure offline navigation:

```text
├── index.html        # Home page with two articles and header/footer
├── about.html        # About page containing semantic tags (figure, aside, time, mark, details)
├── services.html     # Services/Projects page with a semantic 4x5 table
├── contact.html      # Contact form with fieldset, legend, and various input types
├── README.md         # Project documentation and challenge notes
└── assets/           # Local media folder
    ├── logo.png
    ├── web-project.png
    ├── mobile-project.png
    └── team.png
```
